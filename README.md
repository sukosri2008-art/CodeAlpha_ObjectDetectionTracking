Object Detection and Tracking

Overview

This project is a real-time Object Detection and Tracking system developed as part of the CodeAlpha Artificial Intelligence Internship. It uses a pre-trained YOLO model and OpenCV to detect objects in video streams and track them across frames.

Features

- Real-time object detection
- Bounding box visualization
- Object labeling
- Video/Webcam support
- Efficient object tracking
- Live display of detected objects

Technologies Used

- Python
- OpenCV
- YOLO (You Only Look Once)
- NumPy

How It Works

1. Capture video from a webcam or video file.
2. Process each frame using the YOLO model.
3. Detect objects and draw bounding boxes.
4. Assign labels to detected objects.
5. Display the processed video in real time.

How to Run

1. Install required libraries:
   pip install opencv-python numpy

2. Download YOLO model files.

3. Run the program:
   python object_detection.py

4. View real-time object detection results.

Sample Output

- Person detected
- Car detected
- Mobile phone detected
- Multiple objects tracked simultaneously
